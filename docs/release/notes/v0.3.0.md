# Yams v0.3.0

Wording-only memory updates can now preserve the dates of the last substantive
change and verification. Add `"wording_only": true` to an existing JSON update
request through `yams-wiki write` or `yams --write` when correcting phrasing
without changing the claims or evidence. Ordinary updates retain their existing
date-refresh behavior.

## Behavior and compatibility

- Wording-only updates preserve the stored `updated` and `verified` dates.
  The flag is the caller’s assertion that the meaning and evidence are unchanged;
  Yams does not perform a semantic comparison of the prose.
- The stored verification date must be a valid `YYYY-MM-DD` between the stored
  update date and today. Invalid dates are refused rather than silently retained.
- Existing revision checks, transactional writes, catalog updates, and
  supersession handling remain in place.
- `wiki_maintenance: 3` advertises this capability. The page format still has
  the same eight frontmatter fields; indexes and model artifacts are unchanged.
- Initialization recognizes both previously released v1 schema documents and
  can upgrade their authoring guidance through the existing reviewed manifest
  workflow. Customized schema documents remain protected.

## Upgrade

```sh
brew update
brew upgrade yams
brew services restart yams # if the background service is enabled
```

No reindex is required for this release. Restart an enabled background service
so it uses the newly installed executable. Existing write clients can omit
`wording_only` and keep their current behavior.

## Install

Supported channel: `brew install mrseizy/yams/yams`.
Direct tarball downloads are quarantined by Gatekeeper (binaries are
ad-hoc signed only) and are not a supported install path.

## Known limitations

- The first-run model download (~550 MB) is not yet bounded or resumable;
  interrupt with Ctrl-C and rerun if it stalls.
- Apple Silicon only; macOS floor declared :sonoma, validated on the
  version listed above.
- `yams`, `memory-search`, `yams-service`, and `yams-wiki` all report
  their package version with `--version`.
