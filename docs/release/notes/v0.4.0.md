# Yams v0.4.0

Yams can now report memory pages that need maintenance, and searches for
absent underscored identifiers no longer return unrelated pages solely because
their similarity score is high. Names such as `OAuth2` and `PostgreSQL` retain
semantic matching for alternate spellings.

## Behavior and compatibility

- `yams-wiki health .agents/memory` reports duplicate current titles or bodies,
  overdue verification, future verification dates, and uninterpretable legacy
  dates. It reads the pages directly without a model or search index.
- Health findings are advisory: they exit successfully and never rewrite pages
  or change ranking. The default review interval is 180 days; use `--stale-days`,
  `--as-of YYYY-MM-DD`, and `--json` to customize or automate reports.
  `memory_health: 1` advertises the new capability.
- A single ASCII underscored identifier must appear at identifier boundaries
  in indexed text or a title, ignoring case. An absent symbol returns exit 3
  for a single-project search. `--no-gate` still returns candidates;
  `--explain` adds `gate.identifier_dropped`.
- Capitalization and digits alone do not trigger the new guard. Ordinary prose,
  multilingual queries, and names without underscores retain semantic retrieval.
  The existing score gates, exact-match rescue, and supersession behavior remain.
- Page and index formats, service transport, and model artifacts are unchanged.
- Developers can run the new opt-in retrieval benchmark against fictional
  fixtures. It reports recall, false positives, latency, and context size;
  the benchmark is not included in the release archive.

## Upgrade

```sh
brew update
brew upgrade yams
brew services restart yams # if the background service is enabled
```

No reindex is required. Restart an enabled background service so searches use
the new executable. Run `yams-wiki health .agents/memory --json` to inspect the
new advisory report.

  (3 intentionally ignored), release build, and warning-free documentation.
- Release-contract and package-contract tests passed, along with fresh-model
  direct/service smoke and the pinned Jina contract. All four staged commands

## Install

Supported channel: `brew install mrseizy/yams/yams`.
Direct tarball downloads are quarantined by Gatekeeper (binaries are
ad-hoc signed only) and are not a supported install path.

## Known limitations

- Retrieval supplies leads, not proof that a passage answers a question.
  Unsupported prose questions and absent names without underscores can still
  return related pages; verify the requested fact against the source.
- The first-run model download (~550 MB) is not yet bounded or resumable;
  interrupt with Ctrl-C and rerun if it stalls.
- Apple Silicon only; macOS floor declared :sonoma, validated on the
  version listed above.
