# Yams v0.2.1

This patch restores searches of indexes created by v0.1.0. Version 0.2.0
incorrectly required the new `supersessions` table during read-only retrieval,
causing `store_operational: no such table: supersessions` until a project was
reindexed. Direct, service, and `--all` searches now read those existing schema
v2 indexes without modifying them.

## Upgrade

```sh
brew update
brew upgrade yams
brew services restart yams # if the background service is enabled
```

Restart an enabled service after upgrading so it runs the fixed binary.
No reindex is required to restore searches. Run `yams --index` when you want
to backfill the replacement metadata introduced in v0.2.0; the existing
transactional migration and embedding reuse behavior are unchanged.

The fix applies specifically to schema v2. A damaged current-schema index
still reports an error instead of silently ignoring a missing table.
There are no capability, protocol, or agent-skill changes in this patch.

## Validation

- Regression tests cover direct and service search, including `--all`, against
  schema v2 fixtures and verify that the index bytes remain unchanged.
- A separate regression confirms that a current-schema index with a missing
  `supersessions` table still fails explicitly.
- The release candidate successfully searched three existing project indexes
  without reindexing, including the index that reproduced the reported failure.
- The upgrade acceptance checklist now requires queries of a previous release's
  index before reindexing, through both direct and restarted-service paths.
- Claude reviewed the code and the final acceptance-checklist changes.

## Install

Supported channel: `brew install mrseizy/yams/yams`.
Direct tarball downloads are quarantined by Gatekeeper (binaries are
ad-hoc signed only) and are not a supported install path.

## Known limitations

- The first-run model download (~550 MB) is not yet bounded or resumable;
  interrupt with Ctrl-C and rerun if it stalls.
- Apple Silicon only; macOS floor declared :sonoma, validated on the
  version listed above.
- `yams`, `memory-search`, `yams-service`, and `yams-wiki` all report
  their package version with `--version`.
